# Ressources

Références Lua grandMA3 utilisées pour le Plugin Song Creator. Chaque dossier garde sa licence
d'origine et un `SOURCE.md` (adresse et version copiée).

| Dossier | Contenu | Licence |
|---|---|---|
| `GrandMA3-API-Documentation/` | documentation de l'API Lua (Object API, Object Free API, mots-clés, exemples) | MIT (MacTirney) |
| `GrandMA3-Lua-BakaCowpoke/` | plugins d'exemple, référence des éléments d'interface (`UI Reference/`), couleurs du thème | CC0 (BakaCowpoke) |
| `GrandMA3-Reference-patopesto/` | référence de [grandma3.bambinito.net](https://grandma3.bambinito.net/reference/) : API Lua **2.3** complète (dump de la console), enums, arbre des objets, exemples de fenêtres. Aide-mémoire `API_2.3.md` et `ENUMS_2.3.md` | AGPL v3 (patopesto) : documentation seulement, pas de copie de code dans le plugin |

Pour la 2.3 (version de Jo), consulter d'abord `GrandMA3-Reference-patopesto/API_2.3.md` : c'est un dump de la vraie
API, alors que les deux autres références datent de la 1.9.
